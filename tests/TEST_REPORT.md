# 亲智聊 H5 App Demo V2.0 测试报告

## 测试环境

- Chromium Headless
- 手机视口：390×844
- 响应式视口：360 / 375 / 390 / 430px
- 测试对象：内嵌 CSS、JavaScript 和图片的单文件构建

## 核心功能回归

`regression_v20.py`：11 / 11 组通过，浏览器 Page Error 与 Console Error 为 0。

覆盖：

1. 登录、隐私、手机号、验证码和首页进入
2. 点击打开侧栏及主页面联动位移
3. 屏幕左缘手势打开侧栏
4. 首页对话 → 正面解读三阶段 → 行动卡
5. 任务中心 → 成长总结 → 逐级返回
6. 家庭档案家长 / 孩子 / 小亲记忆
7. 我的测评 → 详情 → 测评报告
8. 关系指南分类 / 详情 / 返回链
9. 会员中心 / 会员方案 / 返回链
10. 设置二级页面与返回链
11. 360px / 430px 核心页面无横向滚动

## 返回按钮专项

`back_button_audit.py`：27 / 27 个二级、三级页面返回按钮通过，浏览器错误为 0。

测评报告使用显式返回“我的测评”，避免返回已经完成的答题页；其他页面优先返回实际进入来源。

## 响应式专项

`responsive_audit.py`：24 / 24 项通过，浏览器错误为 0。

验证宽度：360、375、390、430px。

验证页面：

- 首页
- 成长总结
- 关系指南
- 测评报告
- 家庭档案
- 设置

所有被测页面均未产生水平滚动。

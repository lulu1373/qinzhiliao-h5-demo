# 亲智聊 Design System V3.0

## 1. 设计目标

V3.0 将 V2.0 的“统一功能原型”升级为具有品牌场景、编辑感与陪伴感的高保真 H5。业务流程与路由保持不变，重点升级登录首页、AI 首页、聊天/正面解读/行动卡与左侧栏四张黄金页面。

核心表达：暖米背景、雾绿品牌、奶油白内容面、克制杏桃色，以及低对比、柔和的空间层次。

## 3. 字体层级

- 品牌价值标题：透明 PNG 字形资产，避免手机系统字体差异。
- 页面主标题：26–28px / 700。
- 页面标题栏：19px / 700。
- 区块标题：17px / 650。
- 卡片标题：14–16px / 600–650。
- 正文：13–14px / 1.65–1.75。
- 辅助文字：10–12px / 400–500。

正文使用系统中文字体栈，不向用户分发字体文件。

## 4. 表面与层级

- 主卡片：半透明奶油白、极弱绿灰描边、双层柔光阴影。
- 普通内容卡：不透明或 75%–85% 白色，弱描边。
- 列表：优先使用容器分组与细分隔线，不为每一行单独画卡片。
- 页面背景：暖米—雾绿渐变，并叠加 1.7% 纸张噪点。

## 5. 圆角

- 主视觉区：26–28px。
- 主卡片：24–26px。
- 普通卡片：20–22px。
- 图标底座：12–14px。
- 胶囊：999px。
- Bottom Sheet：顶部 28px。
- 左侧抽屉右边缘：27px。

## 6. 图标

- 24×24 viewBox。
- 线宽 1.7–1.8px。
- `stroke-linecap: round`。
- 使用 `currentColor` 控制状态。
- 正式功能入口不使用系统 Emoji；情绪反馈表情仅作为结果语义保留。

## 8. 关键页面

### 登录首页

品牌区、定制标题、场景小亲、三个价值胶囊与底部登录操作形成一张完整的欢迎海报，但按钮和协议仍是真实 DOM。

### AI 首页

顶部品牌工具栏；中部由背景、植物、桌面、小亲和真实问题胶囊构成 2.5D 场景；成长总结与问题列表进入滚动内容区；底部输入框为悬浮 Dock。

### 聊天与正面解读

聊天顶部简化为返回、标题/在线状态、声音、更多。用户消息为浅绿气泡；小亲消息为奶油白卡；正面解读和行动卡使用独立层级，继续嵌入同一聊天流。

### 左侧栏

用户信息、深橄榄会员卡、三项核心服务、任务/消息快捷区、最近对话与底部工具区。抽屉打开时主页面仅轻微位移并缩小，不再整体平移一个抽屉宽度。

## 9. 动效

- 角色呼吸：3.8–4.2 秒弱循环。
- 按钮按压：`scale(.965–.98)`。
- 抽屉：250ms 高阻尼缓动。
- 主页面抽屉联动：18px 位移、最大 1.5% 缩小、24% 遮罩。
- 消息与卡片：180–220ms 上移淡入。
- 正面解读进度：`transform: scaleX()`。

## 10. 性能约束

- 全部场景图为 SVG/WebP。
- 独立 HTML 构建时资产转 Data URI。
- 大范围滚动区避免高强度模糊。
- 抽屉只动画 `transform`、`opacity` 和轻量圆角。
- 支持 `prefers-reduced-motion`。

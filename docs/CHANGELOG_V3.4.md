# V3.4 — 任务与消息入口整理

## 入口

- 首页顶部：侧栏、品牌、声音、更多。移除礼物按钮，不新增替代入口。
- 左侧栏：保留任务中心与消息中心。
- 更多：保留意见反馈、Demo 工具、网络模拟；移除消息中心。
- 首页成长总结保持原样。

## 数量与状态

任务角标表示待处理项数；进入任务中心不会减少它。完成行动反馈或测评后才更新。
消息角标表示未读数；逐条打开或全部已读只更新消息状态。
同一行动提醒引用原 action ID，不另外生成一条待办；旧通知在对应事项已完成时打开现有结果。
测评的进度按测评 ID 保存，用于任务列表与测评列表一致展示。

## 兼容和范围

保留 V3.x 本地存储 key；将旧 unread 数字迁移为消息已读状态，任务数字重新由数据计算，不清除已有账号、对话、行动和反馈。浏览器允许本地存储时保存；不允许时使用既有内存回退。
保留 V3.3 的抽屉白边修复、路由栈、页面尺寸及视觉资产。

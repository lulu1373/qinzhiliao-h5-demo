# V3.5 侧栏统一滚动版

基线：本对话交付的 V3.4 入口整理版。没有引入其他对话方案，没有推送 GitHub。

## 本次改变

- 紧凑账号栏固定在顶部：头像/昵称进入个人资料，设置为轻入口，消息/任务图标和数量角标保留，关闭按钮并入同一行。头部76px（不含顶部安全区）。
- 一个原生滚动容器 `#drawerScroll` 承载会员权益条、三个常用功能、最近对话及末端客服。旧 `.drawer-history` 独立滚动和 `.drawer-bottom` 固定栏不再出现在 DOM 中。
- 会员由大幅深色横幅变为56px轻权益条；三个功能入口共用轻背景，不再逐个套厚卡片。
- 最近对话48px行高、14px正文，无装饰绿点、日期分组或每行箭头。打开过的当前对话有浅绿选中背景。
- 在内容任意位置起手都使用浏览器的同一纵向滚动；确认横向意图后才捕获指针。手势后抑制合成误点击，新的点击不受影响。
- 从侧栏进入内页后返回到首页来源时，恢复展开的侧栏和浏览位置；途中三级页面仍按实际访问路径逐级返回。显式“和小亲聊聊”等操作不会误打开侧栏。
- 同一往返还保留首页滚动位置和未发送草稿。滚动/展开位置是当前会话UI状态，不承诺刷新后恢复。

## 保留范围

- 抽屉宽度、translateX(-100%)、关闭隐藏/阴影/inert处理沿用V3.3；不再修改宽度常量。
- V3.4 的任务/消息唯一入口、独立计数与通知跳转逻辑保留。
- 首页、对话、正面解读、行动卡、测评、指南和会员业务不在本次重设计范围。
- 原品牌图像资产未改。
- 不增加没有真实数据同步的下拉刷新转圈。

## 结构（替换原V0.3的独立历史滚动规则）

```text
侧栏
├─ 紧凑账号栏（固定；76px + 顶部安全区）
│  ├─ 头像/昵称 → 个人资料
│  ├─ 设置
│  ├─ 消息 + 未读数
│  ├─ 任务 + 待处理数
│  └─ 关闭
└─ drawerScroll（唯一原生纵向滚动）
   ├─ 轻量会员权益条
   ├─ 家庭档案 / 我的测评 / 关系指南
   ├─ 最近对话（同一流；不设独立滚动）
   └─ 联系客服（末端普通入口，不再固定）
```

# 亲智聊 H5 Demo V3.7 专项测试报告

## 本轮问题
1. 个人资料“更换头像”缺少真实界面和操作闭环。
2. 家庭身份为自由输入，容易导致称呼与档案关系不一致。
3. 从侧栏进入二级功能页再返回时，右侧可见的聊天背景发生滚动/转场跳动。
4. 成长总结“最近行动记录”受到浏览器默认 button 样式影响，出现粗边框、宽度不一致和信息层级杂乱。

## 修复与验证

| 项目 | 验证结果 |
|---|---|
| 家庭身份固定选项 | PASS |
| 头像更换 Bottom Sheet | PASS |
| 本地图片选择后 256px 压缩预览 | PASS |
| 最近行动记录三行宽度 | 328 / 328 / 328 px |
| 最近行动记录左右/顶部浏览器默认边框 | 0 px |
| 侧栏→任务中心→返回，聊天草稿 | 保留 |
| 侧栏→任务中心→返回，Home scrollTop | 完全一致 |
| 返回时 page-enter 动画类 | 无 |
| 返回前后右侧 45px 可见区域像素差 | 0 |
| 二/三级页面返回专项 | 27 / 27 PASS |
| Page Error / Console Error | 0 |

## 根因补充
V3.6 的聊天滚动区使用 `scroll-behavior:smooth`。返回时即使恢复的是正确 `scrollTop`，赋值过程也会被表现成平滑滚动，因此用户透过侧栏右侧可见区域会看到聊天内容“滑过去”。V3.7 在恢复瞬间临时切到 `scroll-behavior:auto`，完成定位后再恢复原有平滑滚动配置。

自动化环境：Chromium 390×844。尚未替代 iOS Safari、Android Chrome 与微信内置浏览器实机验证。

# V3.2 无侧边残影专项测试

## 问题根因

V3.1 已经取消了 480px 宽度上限，但页面进入动画仍使用：

```css
transform: translate3d(12%, 0, 0)
```

因此在首页或二级页刚渲染的前约 280ms，页面会向右偏移并露出左侧底层背景。在 ChatGPT 文件预览、iframe 或暂停动画的 WebView 中，这可能被看到为持续的白色弧形边。

截图最左侧的黑色区域属于 ChatGPT 文件预览器本身，不在 H5 DOM 内；H5 内部可修复的是紧贴页面的白色弧形条。

## 修复

- 页面进入/返回动画改为仅透明度变化，不再做 X 轴平移。
- `body / #app / .app-frame` 固定覆盖完整 visual viewport。
- `.screen` 在任意转场帧都强制 `left: 0; right: 0; width: 100%`。
- 路由渲染后清除动画类和残留 transform。
- 侧栏关闭时主页面严格归零；侧栏打开时仍保留产品要求的轻位移与圆角。

## 测试

测试宽度：320、360、390、430、517、768px。

每个宽度均检查：

- 首页进入 0ms / 40ms / 340ms；
- 任务中心进入 0ms / 40ms / 340ms；
- App Frame 起点为 0；
- Screen 起点为 0；
- 宽度等于视口；
- Transform 为 none；
- 无横向滚动；
- Page Error 为 0。

## 结果

- 6 个视口全部通过
- 36 个转场采样点全部通过
- 横向溢出：0
- Page Error：0

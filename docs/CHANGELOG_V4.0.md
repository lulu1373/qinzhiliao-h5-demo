# V4.0 语义多色视觉升级

基于 V3.9 的交互与导航结构，仅升级视觉语义，不改变功能流程。

## 代表页面
- AI 首页：四类入口拥有低饱和语义色身份。
- 正面解读：事实蓝 / 孩子绿 / 家长桃 / 关系紫 / 结论暖绿。
- 行动卡：奶油黄主面 + 杏桃行动色 + 绿色原因说明。
- 成长总结：绿为主轴，数据卡加入蓝 / 桃 / 奶油黄区分。
- 我的测评：建立独立的专业蓝体系。
- 左侧栏：家庭档案绿 / 我的测评蓝 / 关系指南桃；消息任务设置保持中性。

## 原则
- 色彩用于表达信息语义，而非装饰。
- 一张页面仍然只保留一个主色重心。
- 正文和主要文字不彩色化。
- 保留 V3.9 Persistent Home / Drawer / PageStack / 连续对话等 UX。

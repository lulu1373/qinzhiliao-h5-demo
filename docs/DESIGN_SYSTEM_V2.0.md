# 亲智聊 Design System 2.0

## 1. 视觉主题

名称：**暖米雾绿 · Afu Shell**

设计目标：保留蚂蚁阿福式的页面秩序、AI 入口、卡片组织和抽屉交互，以亲智聊自己的绿色品牌、米色背景、小亲形象和家庭关系内容重新表达。

## 2. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--bg` | `#F3EEE6` | 暖米页面背景 |
| `--surface` | `#FFFCF8` | 一级内容表面 |
| `--surface-2` | `#F8F5EF` | 次级内容表面 |
| `--text` | `#282C26` | 一级文字 |
| `--muted` | `#687066` | 二级文字 |
| `--muted-2` | `#9AA097` | 辅助文字 |
| `--green` | `#5F9B4C` | 品牌主色与 CTA |
| `--green-soft` | `#EAF4E4` | 选中态和图标底座 |
| `--warm` | `#F1A268` | 温暖提醒与次级强调 |
| `--blue` | `#667FD6` | 低频功能色 |
| `--danger` | `#D56A5E` | 删除、危险操作 |

色彩比例：中性色约 70%，品牌绿约 20%，暖色约 7%，功能色约 3%。

## 3. 字体层级

- 品牌问候：28 / 36，700
- 页面标题：19—20 / 28，700
- 大卡标题：17—18 / 26，650—700
- 模块标题：16—17 / 24，650
- 卡片标题：15 / 22，600
- 正文：14 / 22，400—500
- 辅助说明：12 / 18，400
- 标签：10—11 / 16，550—650

不再大面积使用 850/900 字重。

## 4. 图标

- 24×24 基础画布
- 1.7—1.75px 线宽
- 圆形端点与圆形转角
- SVG 使用 `currentColor`
- 业务图标拥有统一的浅色底座
- 功能入口不使用系统 Emoji
- `🙂 / 😐 / 🙁` 只作为行动反馈结果保留

## 5. 表面层级

### Level 0：页面背景

暖米色与极浅雾绿光晕。

### Level 1：主功能卡

- 半透明白色
- 24px 圆角
- 极弱描边
- 14—18px 柔和阴影
- 轻量模糊背景

用于首页成长卡、正面解读、测评报告、成长摘要。

### Level 2：普通内容卡

- 奶油白
- 20—22px 圆角
- 更克制的阴影

用于任务、成员档案、内容卡和设置组。

### Level 3：列表行

不用独立卡片；依靠留白、浅分割线和按压背景表达。

## 6. 核心组件

### Top Bar

- 58px 高
- 半透明背景和模糊
- 44×44 点击热区
- 标题 18px / 650

### Primary Button

- 绿色轻渐变
- 17px 圆角
- 50px 高
- 650 字重
- 按压缩放至 0.975

### Bottom Composer

- 作为悬浮工具条呈现
- 半透明白色
- 28px 圆角
- 柔和浮层阴影
- 语音、输入、附件和发送形成一个整体

### Side Drawer

- 宽度 87%，最大 380px
- 奶油白至雾绿的极浅渐变
- 主页面随抽屉同步右移
- 页面蒙层最大约 0.26—0.30
- 顶部账号区和底部工具区固定
- 对话记录独立滚动

### Positive Interpretation

- 绿色连续进度轨
- “还原事件 / 理解关系 / 确认理解”三个阶段
- 最终结果拆为“表面行为 / 孩子侧 / 家长侧 / 互动循环 / 结论”
- 不使用诊断或警告视觉

### Action Card

- 浅绿到暖米渐变
- 一个最小行动
- 独立话术引用区
- 失败兜底话术
- 明确说明行动与关系理解的连接

## 7. 响应式

- 设计基准：390px
- 验证宽度：360 / 375 / 390 / 430px
- 使用 `100dvh` 与 Safe Area
- 手机端全屏，无模拟手机壳和左右白边
- 所有主要点击区域不小于 44×44px

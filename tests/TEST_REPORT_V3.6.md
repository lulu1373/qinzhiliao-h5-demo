# 亲智聊 H5 Demo V3.6 连续会话专项测试报告

## 本轮目标

把首页与聊天从“二选一切换”改为同一页面中的连续会话：开始聊天后首页内容仍在上方，用户消息和 AI 回复直接追加到原页面下方；顶部栏与底部输入框不重建。

## 自动化环境

- Chromium Headless
- 390 × 844 手机视口
- 单文件 H5 构建

## 已验证项目

1. 点击首页推荐问题后，路由仍为 `home`。
2. 首页欢迎区仍存在，没有被聊天页替换。
3. 顶部栏不切换为“返回箭头 + 小亲”的二级页样式。
4. 顶部栏 DOM 在连续会话过程中保持同一个节点。
5. 输入框 DOM 在连续会话过程中保持同一个节点。
6. AI 回复过程中未发送草稿保持不变。
7. 点击声音开关不会重建输入框，也不会清掉草稿。
8. 第一轮问题、第二轮追问、正面解读邀请均在同一连续消息流中推进。
9. 还原事件确认后，会话历史保留阶段小结。
10. 最终正面解读确认后，完整理解卡仍保留在聊天历史。
11. 行动卡确认后，行动卡仍保留并显示“已加入成长总结”。
12. 最终理解卡在行动卡出现后仍可向上回看。
13. 整个核心对话流程中 `screenHost` 页面根节点替换次数为 0。
14. 用户上滑查看历史后，新回复不会强制拉回底部；显示“有新回复”入口。
15. 左侧抽屉仍可正常打开。
16. 从侧栏进入设置等二级页后仍可正常返回首页。
17. JavaScript Page Error：0。
18. Console Error：0。

## 关键行为变化

### V3.5

`首页未聊天态 → 整页替换 → 聊天态`

### V3.6

`首页内容 → 继续向下追加用户消息 → AI 回复 → 正面解读 → 行动卡`

顶部栏、滚动容器和输入框保持稳定。

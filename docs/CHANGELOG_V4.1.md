# V4.1 · 全 App 视觉收口

基线：V4.0 语义多色视觉升级版。

本轮不修改连续聊天、PageStack、Persistent Home/Drawer、资料编辑或业务状态机，只把 V4.0 已验证的语义色和表面层级完整铺到剩余页面。

## 语义颜色

- 绿色：品牌、孩子、成长、隐私可控
- 杏桃：家长压力、行动、提醒、待处理
- 蓝色：事实、观察、测评、帮助信息
- 紫色：关系模式、AI 记忆、深度理解
- 奶油金：计划、提示、会员权益、温暖承接

## 本轮覆盖

- 登录子流程：手机号、验证码、本机号、微信授权、登录成功
- 个人资料、头像裁切、昵称、家庭身份编辑
- 家庭档案：家长、孩子、小亲记忆、家庭成员、基础档案
- 关系指南：首页、分类、文章详情
- 会员中心、方案、订单
- 任务中心、消息中心
- 设置、账号与安全、通知、隐私、帮助、关于
- 意见反馈
- 成长周总结、行动详情、全部行动记录
- 公共 Bottom Sheet、Toast、空状态、加载态、错误态

## 设计原则

颜色只用于图标底座、浅表面、状态和少数关键动作；正文和大面积背景继续使用中性色，避免“彩色儿童 App”。

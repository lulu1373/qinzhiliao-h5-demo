# 亲智聊 H5 App Demo V3.0

V3.0 是基于 V2.0 完整功能逻辑完成的“黄金页面质感升级版”。本次重点重做登录首页、AI 首页、聊天/正面解读/行动卡和左侧栏，并保留其余二级、三级页面与返回链路。

## 直接打开

打开 `dist/index.html`，或使用外部单文件：

`亲智聊-H5-App-Demo-V3.0-质感升级版.html`

## 登录体验

1. 勾选服务协议。
2. 点击手机号登录。
3. 输入任意 11 位手机号。
4. 输入任意 6 位验证码。

## 核心体验

首页点击“刚刚发生什么了”，依次完成两轮推荐问题；点击“一起看看”进入正面解读；确认关系理解后点击“看看小行动”体验行动卡。

## 文件结构

- `app.js`：业务状态机、路由、侧栏手势。
- `styles.css`：V2 基础样式与 V3 黄金页面覆盖层。
- `assets/v3/`：V3 品牌、场景、角色与纹理资产。
- `dist/index.html`：完全自包含的单文件版本。
- `docs/`：设计系统与版本记录。
- `tests/`：截图、返回和响应式审计。

- 主 CTA 从橙色改为亲智绿色
- 页面背景调整为暖米＋雾绿柔光
- 统一文字色和层级，减少过重字重
- 统一主卡、内容卡和列表的表面层级

- 新增 20+ 个统一圆角线性 SVG 图标

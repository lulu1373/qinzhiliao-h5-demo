# V4.2 · 暖米视觉重构

V4.2 基于 V4.1，只调整视觉系统，不改变交互流程与数据逻辑。

## 核心视觉规则

- 米色是环境
- 白色是内容
- 橙色是动作
- 绿色是品牌 / 成长
- 蓝色是专业 / 观察
- 紫色是关系 / 深度理解

## 主要调整

- 大面积页面背景统一回到暖米 / 奶油白。
- 首页场景降低绿色饱和度，推荐入口卡片统一为暖白，只保留图标语义色。
- 正面解读由多张彩色卡改成一张暖白卡 + 蓝/绿/橙/紫细色条。
- 行动卡以奶油白为主体、橙色作为行动信号。
- 成长总结去掉大面积浅绿背景，颜色只落在指标与状态。
- 测评回到暖米背景，蓝色只用于进度、选中和专业指标。
- 侧栏/家庭档案/指南/设置等页面统一暖米外壳与白色内容表面。
- 会员保留唯一大面积深橄榄身份卡。
